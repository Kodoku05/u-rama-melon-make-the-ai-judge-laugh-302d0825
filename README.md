A one-line office joke built around the gap between management's invitation to
speak and the procedures that govern speaking. A familiar administrative reflex
turns the request back on itself; the last beat stays deadpan.
The candidate scores and tightness revision are in [CANDIDATES.md](CANDIDATES.md).

Run with Node.js 22, using only its standard library:

```sh
node main.ts
```

The program creates `/output/entry.txt` as UTF-8, without a trailing newline.
It rejects blank, multiline, or out-of-range text before writing. To run locally
with a writable output directory:

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
